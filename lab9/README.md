# Lab 09 / Interactive Unity 3D Scene

> Explore first-person/third-person-style player movement, objects, collection and an in-game HUD.

**Stack:** Unity · C# / Editor scripting

## Objective

Explore first-person/third-person-style player movement, objects, collection and an in-game HUD. This experiment is part of the **CS4104 Computer Graphics and Virtual Reality** lab collection.

## Concept

The retained Unity C# sources include a scene auto-setup utility, player controller, follow camera, rotating objects, collectibles and the HUD. The original standalone repo is retained intentionally.
